# Economia familiar

Tauler privat de l'economia de casa, publicat amb GitHub Pages.

La pàgina (`index.html`) està **xifrada** (AES-256-GCM, clau derivada amb PBKDF2-SHA256, 600.000 iteracions). Sense la contrasenya només es veu la pantalla d'accés; les dades no són llegibles ni al codi font.

Les dades en clar, els scripts i la contrasenya viuen a `privat/`, que és a `.gitignore` i no es puja mai.
